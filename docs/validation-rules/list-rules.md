# List rules <Badge type="info" text="LIVR 2.5" />

List rules check a list as a whole: the number of items and duplicates. To validate every item, use [`list_of`](/validation-rules/list_of.html). List rules return `FORMAT_ERROR` for anything that is not a list.

These rules were added in [LIVR 2.5](/changes.html#v2-5).
