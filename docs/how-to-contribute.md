# How to contribute

LIVR is a small specification with a large ecosystem, and there are several ways to help:

- **[Create your own implementation](/how-to-contribute/create-own-implementation.html)** for a language that does not have one yet, or adopt an existing implementation that is no longer maintained.
- **[Improve the test suite](/how-to-contribute/test-suite.html).** Every new edge case makes all implementations more consistent.
- **[Create plugins](/how-to-contribute/create-own-plugins.html)**: extra rules, framework integrations and tools built on LIVR.
- **[Improve this documentation](/how-to-contribute/improve-livr-documentation.html).** Every page has an "Edit this page on GitHub" link at the bottom.
- **[Tell us that you use LIVR](/users.html)** and add your logo to the users page.

Questions and ideas are welcome in [GitHub issues](https://github.com/koorchik/LIVR/issues).
